# TileMuse

TileMuse is a responsive tile gallery web application built with Next.js. The project allows users to explore different tile designs, search tiles, view detailed information, create an account, log in, and manage their profile.

## Purpose

The purpose of TileMuse is to provide a simple and modern platform for browsing tile collections while demonstrating authentication, protected routes, dynamic data, user profile management, and responsive web development.

## Live URL

https://tile-muse.vercel.app

## Key Features

- Browse featured tiles
- View all tile collections
- Search tiles by title
- Dynamic tile details pages
- Email and password registration
- Email and password login
- Google authentication
- User logout
- Protected tile details and profile routes
- View user profile
- Update user name and profile image
- Responsive design for mobile, tablet, and desktop
- SwiperJS tile slider
- Loading states
- Error handling
- Custom 404 page
- Tile data loaded from local JSON
- MongoDB used for authentication and user data
